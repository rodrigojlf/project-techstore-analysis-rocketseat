# 📊 EDA Tech Store - Rocketseat

## 💻 Sobre o Projeto

Este projeto faz parte do desafio prático **EDA Tech Store** da formação em Data Analytics da **Rocketseat**.
O objetivo principal é implementar, do zero, um sistema de análise de dados de vendas utilizando Python para explorar um conjunto de dados em formato CSV. O sistema carrega os dados, exibe informações básicas, realiza consultas específicas e pode gerar visualizações e relatórios.

## 🛠️ Tecnologias Utilizadas

* **Python**
* **Pandas** (Análise e manipulação de dados)
* **Google Colab** (Ambiente de desenvolvimento)

## 🗂️ Estrutura do Projeto

O projeto está organizado da seguinte maneira:

* `dados/vendas.csv`: Dataset original fornecido pela Rocketseat contendo o histórico de vendas.
* `project_techstore_analysis.ipynb`: Notebook principal contendo todo o código da Análise Exploratória de Dados (EDA) e as resoluções do desafio.

## 🎯 Tarefas e Desafios Realizados

De acordo com as instruções da plataforma, o checklist de desenvolvimento contemplou:

* ✅ Carregamento do arquivo CSV utilizando Pandas.
* ✅ Exibição das primeiras 5 linhas do dataset (`head`).
* ✅ Extração de informações básicas da estrutura dos dados (`info`) e resumos estatísticos (`describe`).
* ✅ Filtragem de dados e consultas específicas (ex: isolar as vendas da categoria "Eletrônicos").
* ✅ Cálculos, agrupamentos e sumarização de informações de vendas.
* ✅ (Opcional) Geração de visualizações gráficas e relatórios baseados nos dados.

## 🚀 Como Executar o Projeto

1. Clone o repositório para a sua máquina local:
```bash
git clone https://github.com/rodrigojif/project-techstore-analysis-rocketseat.git

```


2. Acesse a pasta do projeto:
```bash
cd project-techstore-analysis-rocketseat

```


3. Certifique-se de ter o Python e as bibliotecas necessárias instaladas. Você pode instalar o Pandas e o Jupyter via pip:
```bash
pip install pandas jupyter

```


4. Inicie o servidor do Jupyter Notebook:
```bash
jupyter notebook

```


5. No navegador, abra o arquivo `project_techstore_analysis.ipynb` e execute as células sequencialmente para visualizar a análise.

6. Você também pode executar o projeto importando-o no Google Colab.
